# 🎮 WordClash

Aplikasi Game Adu Kata Multiplayer Berbasis Web.

> Silakan merujuk ke file [README.md utama di root project](../README.md) untuk panduan lengkap instalasi, arsitektur, dan cara menjalankan proyek.

## 🚀 Ringkasan Perintah Cepat

### Run Server (Backend):
```bash
cd server
npm install
npm start
```

### Run Client (Frontend):
```bash
cd client
npm install
npm run dev
```
